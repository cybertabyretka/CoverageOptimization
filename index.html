Field model
u = (x - x0)cosθ + (y - y0)sinθ
n = −(x - x0)sinθ + (y - y0)cosθ
σ(z) = 1 / (1 + e−z)

S(x,y) = [σ(k1u)]p1 · [σ(k2(L − u))]p2 · [σ(k3(n + W/2))]p3 · [σ(k4(W/2 − n))]p4
g∥(u) = [σ(k1u)]p1 · [σ(k2(L − u))]p2
g⊥(n) = [σ(k3(n + W/2))]p3 · [σ(k4(W/2 − n))]p4

F = Σ g∥(ui)·g⊥(ni) − k6·Σ softplus(k5(ε − di))
di = √((x0−xi)² + (y0−yi)² + δ²)
k₁–k₄, p₁–p₄ — параметры покрытия; k₅ (sharpness), k₆ (weight) — параметры штрафа за близость.
