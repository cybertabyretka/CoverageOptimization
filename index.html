Used function
u = (x - x0)cosθ + (y - y0)sinθ
n = −(x - x0)sinθ + (y - y0)cosθ

S(x,y) = [σ(k1u)]p1 · [σ(k2(L − u))]p2 · [σ(k3(n + W/2))]p3 · [σ(k4(W/2 − n))]p4
σ(z) = 1 / (1 + e−z). This formula draws a soft coverage strip with length L, width W, and angle θ around the point (x0, y0).
